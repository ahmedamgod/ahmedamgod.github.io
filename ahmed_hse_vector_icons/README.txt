AHMED AMgad — HSE Portfolio Vector Icons
=========================================
Contains 24 editable SVG vector icons inspired by the highlighted icon concepts
in the portfolio mockup. These are recreated as clean vector paths, not cropped
from the screenshot. They scale without pixelation and use currentColor.

USAGE IN HTML:
<img src="icons/svg/hard-hat.svg" alt="HSE helmet" width="32" height="32" />

For inline SVG, paste the SVG markup directly into your HTML to style stroke
with CSS. Since icons use stroke="currentColor", they inherit the text color
when inline; external <img> SVG files may not inherit page currentColor, so use
CSS filter or inline the SVG if you need dynamic recoloring.

CSS example:
.icon { width: 32px; height: 32px; color: #ff9f0a; }

The SVG files are in the svg/ folder. Each icon has a descriptive filename.
