# رحلة – Rehla 🌿

> كل يوم خطوة صغيرة تقربك من النسخة الأحلى منك.
> رحلتك تبدأ بخطوة… استمر ❤️

تطبيق عربي (عامية مصرية، RTL) لتنظيم العبادات والعادات واليوميات والمشاعر والصحة والأهداف.
بيشتغل كـ **PWA**: بيتثبت على أندرويد زي أي تطبيق، وبيشتغل أوفلاين بالكامل.

## الأقسام
| القسم | اللي فيه |
|---|---|
| الرئيسية | تحية، تاريخ، نقاط، سلسلة أيام، اللي فات، نسبة إنجاز اليوم، ٦ كروت، ذكر اليوم بعدّاد ووضع تركيز، الصلاة الجاية، مهام اليوم، رسالة تحفيزية |
| عباداتي | الصلوات الخمس (الحالة والوقت، مواقيت محسوبة بطريقة الهيئة المصرية حسب موقعك، تقويم التزام، إحصائيات أسبوع/شهر)، القرآن (سورة/آية/صفحات، ورد يومي، تقدّم الختمة، معاد الختمة المتوقع من معدلك الفعلي)، أذكار الصباح والمساء وبعد الصلاة وأذكار خاصة بعدّاد |
| عاداتي | عادات بلا حدود: اسم، أيقونة، لون، وصف، يومي/أيام معينة/كل كام يوم، هدف رقمي، تذكير، تعديل/إيقاف/أرشيف/مسح، سجل وخريطة ١٢ أسبوع |
| يومياتي | كتابة بعنوان وتاريخ وصورة، تعديل ومسح، بحث، تقويم، قفل برقم سري |
| مشاعري | ٩ مشاعر، أسباب، ملاحظات، رسم أسبوعي/شهري، أنماط |
| صحتي | مية، نوم، تمارين، أهداف يومية، إحصائيات الأسبوع |
| رحلتي | أهداف قريبة وبعيدة بخطوات، تحديات ٧ و٣٠ يوم، خط زمني، أرشيف |
| إنجازاتي / تقاريري | نقاط ومستويات وشارات وتقارير — كلها محسوبة من بياناتك الحقيقية |
| الدعم | مساعد شخصي (ملخص، أهداف واقعية، عادات مهملة، اقتراحات)، تمرين تنفس، أسئلة شائعة |
| حسابي | تسجيل/دخول/ضيف، صورة، أهداف شخصية، وضع غامق، شكل الأرقام، إشعارات، تصدير واسترجاع، مسح الحساب |

## التشغيل
ملفات ثابتة بدون build. أي سيرفر static ينفع:
```bash
python3 -m http.server 8000   # وافتح http://localhost:8000/rehla/
```

## التثبيت على أندرويد
1. افتح رابط التطبيق من Chrome.
2. دوس **تثبيت التطبيق** (أو ⋮ ← إضافة للشاشة الرئيسية).

لو عايز ملف **APK / AAB** للـ Play Store: حط رابط التطبيق في [PWABuilder](https://www.pwabuilder.com) واختار Android — هيطلعلك مشروع Trusted Web Activity جاهز.

## ملاحظات تقنية
- **التخزين**: IndexedDB على الجهاز، لكل حساب مساحة منفصلة.
- **الحسابات**: محلية على الجهاز؛ الباسورد متخزن hash بـ PBKDF2-SHA256 (١٥٠ ألف دورة + salt).
- **المزامنة**: تلقائية بين التابات على نفس الجهاز؛ وبين الأجهزة عن طريق تصدير/استرجاع نسخة احتياطية. مفيش سيرفر — المزامنة السحابية محتاجة backend (Firebase/Supabase مثلاً).
- **الإشعارات**: بتشتغل طول ما التطبيق مفتوح أو في الخلفية. الإشعارات المجدولة والتطبيق مقفول تماماً محتاجة push server أو تغليف native.
- **النصوص الدينية**: الأذكار من الأحاديث الصحيحة (حصن المسلم)؛ الآيات بنذكر موضعها بس عشان تتقرا من المصحف.
- **الكود**: `js/store.js` (الحالة والحفظ)، `js/stats.js` (كل الحسابات)، `js/screens/*` (شاشة لكل قسم)، `js/ui.js` (مكونات مشتركة ورسوم بيانية SVG)، `js/art.js` (الرسومات).
